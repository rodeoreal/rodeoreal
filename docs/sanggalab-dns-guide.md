# sanggalab.com 연결 방법 (블루웹)

지금은 아무것도 바꾸지 마세요. 홈페이지가 Netlify에 먼저 올라가야 넣을 값이 나옵니다. 그때 아래 순서대로 하시면 됩니다.

## 0. 지금 해 둘 것 (1분)

1. https://domain.blueweb.co.kr 로그인
2. 상단 메뉴 **도메인 관리**(또는 마이페이지 → 보유 도메인)에서 `sanggalab.com` 클릭
3. **DNS 관리**(메뉴 이름이 "호스트 관리", "레코드 설정", "DNS 레코드"일 수 있음) 화면을 연다
4. 그 화면을 **캡처해서 보내 주세요.** 지금 티스토리에 연결돼 있는지, 네임서버가 블루웹인지 여기서 확인합니다.
   - 네임서버 항목이 `ns1.blueweb.co.kr` 같은 블루웹 주소가 아니면 DNS 설정은 다른 곳에서 해야 합니다. 그것도 캡처에 보이면 됩니다.

## 1. 홈페이지가 올라간 뒤 (제가 알려 드리면)

1. 블루웹 DNS 관리 화면에서 **기존 레코드를 먼저 캡처**해 둡니다 (되돌릴 때 필요).
2. 아래 두 줄을 추가하거나 수정합니다.

| 종류(타입) | 호스트(이름) | 값 |
|---|---|---|
| A | `@` (비워 두는 칸이면 빈칸) | `75.2.60.5` |
| CNAME | `www` | 제가 알려 드리는 주소 (예: `rodeo-realty.netlify.app`) |

   - 같은 호스트(`@` 또는 `www`)에 다른 A/CNAME 값이 이미 있으면 그 줄은 지우고 위 값만 남깁니다. 메일(MX) 레코드는 건드리지 않습니다.
3. **저장**을 누릅니다.
4. 반영까지 보통 몇 분~몇 시간, 길면 하루 걸립니다. 반영되면 Netlify가 https 인증서를 자동으로 붙입니다. 이 단계는 제가 확인합니다.

## 2. 티스토리를 계속 쓰려면

지금 sanggalab.com이 티스토리 블로그에 연결돼 있다면, 블로그는 `blog.sanggalab.com`으로 옮기고 홈페이지가 `sanggalab.com`을 씁니다. 이 경우 레코드 한 줄이 더 필요하고, 티스토리 관리 화면에서도 주소를 바꿔야 합니다. 0번 캡처를 보고 따로 안내드리겠습니다.

## 참고

- `75.2.60.5`는 Netlify가 공식 안내하는 루트 도메인용 주소입니다. 연결 직전에 Netlify 화면에 나오는 값이 다르면 그 값을 따릅니다.
- 문제가 생기면 1-1에서 캡처한 원래 값으로 되돌리면 이전 상태로 돌아갑니다.
