# sanggalab.com 연결 방법 (블루웹)

지금은 아무것도 바꾸지 마세요. 홈페이지가 Netlify에 먼저 올라가야 넣을 값이 나옵니다. 그때 아래 순서대로 하시면 됩니다.

## 0. 지금 할 것

없습니다. sanggalab.com은 아무 데도 연결되지 않은 새 도메인이라 확인할 것도 없습니다. 홈페이지가 올라가면 제가 알려 드립니다.

## 1. 홈페이지가 올라간 뒤 (제가 알려 드리면)

1. https://domain.blueweb.co.kr 로그인 → 도메인 관리 → `sanggalab.com` → **DNS 관리**("호스트 관리", "레코드 설정"일 수 있음). 바꾸기 전에 화면을 캡처해 둡니다.
2. 아래 두 줄을 추가하거나 수정합니다.

| 종류(타입) | 호스트(이름) | 값 |
|---|---|---|
| A | `@` (비워 두는 칸이면 빈칸) | `75.2.60.5` |
| CNAME | `www` | 제가 알려 드리는 주소 (예: `rodeo-realty.netlify.app`) |

   - 같은 호스트(`@` 또는 `www`)에 다른 A/CNAME 값이 이미 있으면 그 줄은 지우고 위 값만 남깁니다. 메일(MX) 레코드는 건드리지 않습니다.
3. **저장**을 누릅니다.
4. 반영까지 보통 몇 분~몇 시간, 길면 하루 걸립니다. 반영되면 Netlify가 https 인증서를 자동으로 붙입니다. 이 단계는 제가 확인합니다.

## 참고

- `75.2.60.5`는 Netlify가 공식 안내하는 루트 도메인용 주소입니다. 연결 직전에 Netlify 화면에 나오는 값이 다르면 그 값을 따릅니다.
- 문제가 생기면 1-1에서 캡처한 원래 값으로 되돌리면 이전 상태로 돌아갑니다.
